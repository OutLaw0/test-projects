# Каталог квартир - Kelnik Apartments

Веб-приложение для отображения каталога квартир с фильтрацией и сортировкой. Разработано на Nuxt 3 с использованием TypeScript и Pinia для управления состоянием.

## 🏗️ Технологический стек

- **Frontend Framework**: Nuxt 3
- **Language**: TypeScript
- **State Management**: Pinia
- **Styling**: CSS3 с CSS Grid и Flexbox
- **UI Components**: Vue 3 Composition API
- **Slider Plugin**: noUiSlider
- **Fonts**: PT Root UI

## ✨ Основные возможности

### 📋 Функциональность
- **Отображение списка квартир** в виде таблицы с информацией о планировке, площади, этаже и цене
- **Фильтрация по параметрам**:
  - Количество комнат (1к, 2к, 3к, 4к)
  - Диапазон цен с ползунком
  - Диапазон площади с ползунком
- **Сортировка** по столбцам:
  - Площадь (S, м²) - по возрастанию/убыванию
  - Этаж - по возрастанию/убыванию  
  - Цена (₽) - по возрастанию/убыванию
- **Пагинация** с кнопкой "Загрузить ещё"
- **Кнопка "Наверх"** для плавной прокрутки в начало страницы
- **Сброс фильтров** к исходному состоянию

### 🎨 Дизайн и UX
- **Адаптивная верстка** для разрешений 960px+ и 1440px+
- **Максимальная ширина контента** 1440px с центрированием
- **Кроссбраузерная совместимость** (Chrome, Firefox, Safari, Edge)
- **Современный UI** с использованием шрифта PT Root UI
- **Интерактивные элементы** с состояниями hover/active
- **Плавные анимации** и переходы

## 🚀 Установка и запуск

### Предварительные требования
- Node.js 18+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для продакшена
```bash
npm run build
```

### Запуск продакшен версии
```bash
npm run start
```

### Генерация статического сайта
```bash
npm run generate
```

## 🔧 Конфигурация

### Основные настройки в `nuxt.config.ts`:
- TypeScript в строгом режиме
- Подключение модуля Pinia
- Глобальные CSS стили
- Шрифты PT Root UI
- Мета-теги для SEO

### API Endpoints:
- `GET /api/apartments` - получение списка квартир с фильтрацией и пагинацией

## 📊 Данные

Приложение использует mock-данные из файла `public/data/apartments.json`, содержащего 60 квартир с параметрами:
- ID квартиры
- Название
- Количество комнат (1-4)
- Площадь (23-190 м²)
- Этаж (1-30)
- Цена (3.3M - 40M ₽)
- URL изображения

## 🎯 Особенности реализации

### Фильтрация
- Реализована на стороне сервера для производительности
- Поддерживает множественный выбор комнат
- Диапазоны цен и площади с ползунками noUiSlider
- Автоматическое обновление при изменении фильтров

### Сортировка
- Клиентская сортировка для быстрого отклика
- Визуальные индикаторы направления сортировки (▲▼)
- Сохранение состояния сортировки

### Адаптивность
- Мобильная версия: одноколоночная сетка
- Планшет (960px+): двухколоночная сетка
- Десктоп (1440px+): трехколоночная сетка для карточек

### Производительность
- Ленивая загрузка изображений
- Виртуализация списка для больших объемов данных
- Оптимизированные запросы к API

## 🛠️ Разработка

### Добавление новых квартир
Отредактируйте файл `public/data/apartments.json`, добавив новые записи в формате:
```json
{
  "id": 61,
  "title": "Название квартиры",
  "rooms": 2,
  "area": 65,
  "floor": 15,
  "price": 8500000,
  "image": "URL_изображения"
}
```

### Изменение стилей
Основные стили находятся в `assets/styles/main.css`. Используются CSS переменные для единообразия цветовой схемы.

### Добавление новых фильтров
1. Обновите интерфейс `FiltersState` в `stores/apartments.ts`
2. Добавьте логику фильтрации в `server/api/apartments.get.ts`
3. Обновите компонент `FilterPanel.vue`
